# c-playground-v2

Playground de C para navegador con editor, ejecución en un Worker y visualizador de memoria.

```sh
pnpm install
pnpm dev --port 5173
pnpm build
```

## Diseño de interfaz

La guía normativa de la UI condensada propia está en [STYLE.md](docs/STYLE.md).
